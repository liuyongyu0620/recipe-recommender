# Recipe Recommender — Food Waste Reduction System

A web-based food management and recipe recommendation system developed as an individual university project. The application helps users reduce food waste by managing ingredients, tracking expiration dates, and recommending recipes based on available ingredients.

## Features

- **User Management:** User registration and login.
- **Ingredient Management:** Add, view, and remove ingredients stored in a virtual refrigerator.
- **Expiration Tracking:** Track ingredient expiration dates to help reduce food waste.
- **Recipe Recommendation:** Recommend recipes based on available ingredients, expiration dates, and dietary preferences.
- **AI Recipe Generation:** Integrate the Groq API to generate recipe suggestions.

## Tech Stack

- **Backend:** Python, Flask
- **Database:** MySQL, SQLAlchemy
- **Frontend:** HTML, CSS, JavaScript
- **AI Integration:** Groq API
